Key file anchors governing each step of the analysis pipeline:

Stop 1: Client State & Validation

public/app.js → validateAndRecalculate()

Inspects each billing row to guarantee end date follows start date and amounts are positive before network submission.

Stop 2: Deterministic Lookback Calculation

src/calculateBackBilling.js → calculateBackBilling()

Calculates the 12-month cut-off date and computes exact daily pro-rata apportionment ((disputableDays / totalDays) * amount) down to the penny. Zero hallucinations.

Stop 3: Live Regulatory Search

src/tavilyClient.js → searchRegulations()

Queries official regulator databases via Tavily (Ofgem SLC 21BA) with an 8-second timeout, extracting official titles, summaries, and source URLs.

Stop 4: Constrained AI Exception & Letter Formatter

src/llmClient.js → evaluateExceptionsAndFormatLetter()

Checks meter obstruction overrides. If unobstructed, calls Gemini with a 4-second timeout to style the formal complaint letter, falling back safely to deterministic templates if offline.

A Practice to Reuse: The 3-Layer Anti-Hallucination Architecture

When building AI-powered consumer or financial applications with AI agents, never let the LLM calculate math or guess statutory rules.

By isolating deterministic arithmetic in a pure, independently tested JavaScript function (calculateBackBilling.js), grounding legal facts in live search retrieval (tavilyClient.js), and constraining the LLM to qualitative exception checks with strict timeouts (llmClient.js), you eliminate hallucinations, protect your users, and ensure zero-failure uptime.
